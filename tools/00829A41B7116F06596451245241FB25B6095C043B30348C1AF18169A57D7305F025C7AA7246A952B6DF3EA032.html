Генератор случайного бинарного числа (бит)

Генерирует случайную бинарную строку длиной N бит, минимум по умолчанию 256 бит. Использует Web Crypto API (криптографически стойкий источник случайности).
Максимум по умолчанию для ползунка — 4096 бит. Поле ввода допускает до 1 000 000 бит, но при очень больших значениях браузер может занять заметное время и память.
Если включён "Принудительный минимум 256 бит", значения < 256 будут автоматически увеличены до 256.
